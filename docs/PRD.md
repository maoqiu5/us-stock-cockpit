# 美股驾驶舱 PRD

更新时间：2026-07-23

## 1. 产品定位

美股驾驶舱是 BrianHub 下的个人投资管理工具，生产入口为 `https://brianhub.net/usstock`。它用于集中查看真实持仓、账户现金、股票池、候选股、模型评分、回测质量、配舱建议和交易纪律。

系统只提供分析、记录、提醒和人工确认前的纪律检查，不自动实盘下单。

## 2. 核心原则

1. 使用真实行情、真实历史数据、真实持仓和真实成交记录。
2. 不使用模拟数据补齐生产判断；数据缺失时宁愿为空、跳过或显示数据质量不足。
3. 每天获取到的股票数据都要写入本地/服务器数据目录，作为后续缓存、复盘和策略依据。
4. 所有功能、算法、数据源、部署或重要文档更新都必须追加 `CHANGELOG.md`；影响产品边界、路线图或数据原则时，再同步更新本 PRD。
5. 网页、数据库、服务器目录必须保持项目隔离，不能破坏 BrianHub 下其他项目。
6. 统一入口由独立 gateway 项目管理，美股项目不负责 Caddy/TLS/80/443。

## 3. 当前功能范围

### 3.1 驾驶舱

- 汇总持仓、市值、现金、盈亏、风险状态。
- 显示美股当前开市/休市状态。
- 保留最后可用行情数据，行情不可更新时不生成模拟值。

### 3.2 股票池

- 股票池页面优先展示合并后的“今日配舱策略”，统一包含账户弹药、8% 现金垫、可动用资金、混合加仓、减仓顺序和仓位优化依据，再展示股票追踪列表。
- 股票追踪列表保持紧凑，只展示现价、涨跌、数据状态、分账户持仓/成本/盈亏/仓位、趋势、中长线策略、纪律价和操作；PE、PEG、ROI、模型分和信号依据不再单独占用表格列。
- PE、PEG、ROI 等指标按当前股价和真实/缓存基本面重新估算。
- 股票池去重，新增标的需通过真实 ticker 校验。
- 显示各账户可用余额。
- 支持在股票池页面手动设置各账户可用现金，尤其是 ZA Bank/uSMART 的线下现金弹药。
- 同一股票可跨多个账户持有；行情和股票模型按标的共用，持仓盈亏、账户仓位、现金垫、执行计划和配舱建议必须按账户分别计算。
- 股票池策略面向中长线投资，强调合理买入区间、分批建仓、目标仓位、风险收益比和退出纪律，不做自动短线量化交易。
- 根据账户现金、现金垫比例、持仓状态和模型评分生成账户级配舱建议；仓位优化不单独占一个大模块，只作为今日配舱策略的依据展示。
- 配舱建议需要给出买入/卖出参考价位，并说明不能交易时的阻断原因。
- 股票池内每只股票可直接打开线下交易录入弹窗，提交后刷新持仓、账户现金和执行计划。
- 所有提交、保存、导入、验证和删除动作都要给出明确成功/失败弹窗反馈。
- 盯盘研判接入本地真实日线缓存计算 MA5、MA20、20 日高低位距离和 ATR 代理指标。
- 缺少日线、VWAP 或相对成交量等真实数据时保持为空，不使用模拟指标。
- 股票池页面显示纪律通知、本地数据资产和盘后复盘摘要，并可手工生成今日快照。

### 3.3 候选股

- 候选股不限制 10 美元以下；搜寻必须来自真实第三方数据源或其缓存。
- 当前候选股来源包括 FMP screener、FMP stock list、Finviz fallback。
- 候选股发现必须服务中长期投资逻辑，优先看公司质量、估值合理性、趋势是否适合建仓、真实数据质量和流动性，不能只按短线热度、异动或低价筛选。
- 候选股动作分为：中长期候选、观察候选、估值偏贵等回调、趋势破坏暂避、暂不纳入。
- 估值过热或趋势过热的标的，即使模型分高，也只能作为观察/等回调，不能直接进入立即执行型建议。
- 候选股结果需写入缓存。

### 3.4 策略模型与回测

- 当前三套模型：
  - `pe_v1`：估值纪律模型。
  - `peg_v1`：成长估值平衡模型。
  - `roi_v1`：质量/资本回报模型。
- 每只股票可对三套模型做多周期验证。
- 回测用于判断策略在真实历史数据上的表现、回撤和数据质量。
- 回测周期不是越长越好，需要结合标的数据完整性、市场阶段和策略适配性。
- 模型验证结果会写入本地数据资产并短期缓存，避免每次打开页面重复重算。

### 3.5 持仓纪律与线下交易

- 支持记录线下买入/卖出动作。
- 线下交易写入本地/云端持久化状态。
- 交易建议必须结合当前行情、当前持仓、账户现金和风控约束。
- 线下交易既可在持仓纪律模块录入，也可在股票池对应股票行内直接录入。

### 3.6 黄金相关状态

- 美股前台已删除黄金盯盘入口和黄金盯盘 UI。
- 后端黄金接口与历史手工黄金记录暂不删除，避免误删既有数据。
- 若未来彻底移除黄金数据，必须先备份并经用户明确确认。

## 5. 部署规则

短期发布方式以用户最新要求为准：

1. 本地改代码。
2. 追加 `CHANGELOG.md` 版本记录；如影响产品边界、路线图或数据原则，再更新本 PRD。
3. 本地验证。
4. 直接同步必要文件到 VPS。
5. 只重建对应业务容器。
6. 不通过 GitHub 发布，除非用户另行要求。

美股项目只允许部署：

- `brianhub-usstock-backend-1`
- `brianhub-usstock-frontend-1`

不要在美股项目里启动 Caddy/Nginx，也不要修改 gateway。除非用户明确要求新增路由、修改 TLS、修改基础认证或调整 BrianHub 统一入口。

## 7. 后续迭代路线图

### P0 稳定性与数据可信度

- 修复旧测试对固定股票池标的的假设，改为状态无关测试。
- 给核心接口增加超时、缓存命中和数据状态测试。
- 给行情、候选股、回测和持仓数据增加统一新鲜度标记。
- 补数据资产清单，展示缓存文件数、记录数、最后更新时间和来源。

### P1 操盘研判增强

- 已接入 5/20 日均线、20 日高低位和 ATR 代理指标；VWAP、相对成交量需等待真实分钟量价源。
- 候选股加入盘前/盘后异动、新闻催化、财报日期和行业热度。
- 配舱建议加入单笔风险预算、分批买入阶梯和账户优先级。
- 缓存或昨收行情只允许观察，不给立即买入建议。

### P2 模型与回测增强

- 三套策略模型增加 walk-forward 验证。
- 已保存最新模型验证结果并做短期缓存；后续增加更完整的历史版本列表。
- 回测报告增加样本长度、胜率稳定性、最大连续亏损、相对 SPY 表现。
- 模型分和盯盘分分离展示，避免短期动量掩盖长期质量。

### P3 盘后复盘与数据资产

- 已支持手工生成每日快照，保存股票池、候选股、持仓、市值、信号和纪律通知。
- 已生成盘后复盘摘要：动作、纪律触发、次日关注；后续可自动定时生成。
- 对线下交易记录做执行复盘：买入价相对建议区间、止损纪律是否触发。

### P4 通知与多项目协同

- 已增加现金垫不足、股票池风险、非实时行情和候选股刷新中的纪律通知。
- 与 BrianHub 其他项目保持 gateway 和数据库边界隔离。
- 如未来接入券商 API，仍默认人工确认，不自动实盘下单。
